## The problem

Dead Atlantic needed a lookbook page, and Shopify's default image handling was working against the product photography rather than for it, automatically cropping images instead of preserving how they were actually shot. Products needed to sort themselves by category instead of being organized by hand, and the navigation needed an animation refresh to match where the brand was heading.

## What I built

### A lookbook that respects the photography

I built a custom lookbook page that preserves each image's native aspect ratio instead of letting Shopify's automatic optimization crop it down.

### Categorization that pulls from the admin

Products now sort automatically based on the "Product Type" field set in the Shopify admin, instead of needing manual sorting every time inventory changes.

### Navigation and branding refresh

I updated the navigation menu with animation to match a reference site the brand was working toward, and implemented an unmodified black version of the logo across the site.
